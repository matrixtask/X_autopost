# X Autopost — インタビュー駆動のストック型X運用

毎朝Slackに届くインタビューに普段の言葉で答えるだけで、**本人の文体のまま**Xのポストがストックされ、品質の高いものだけが自動で予約投稿される仕組みです。クラウド（Google Apps Script + スプレッドシート）で完結し、サーバーの運用は不要です。

## 毎日のルーティン（あなたがやること）

1. **朝8時、Slackにインタビューが届く**（テーマは 定番 / 時事 / ネタ から自動選定）
2. **スレッドに走り書きで返信する**（1〜2分。「スキップ」「終了」も使える）
3. 終わり。あとは全部自動:
   - 回答から本人の文体でポスト下書きを生成 → スプレッドシートにストック
   - 夜21時に品質ゲート（Claudeが100点満点で採点）→ 合格分だけ予約枠へ
   - 毎時のチェックで予約時刻を過ぎたものをXへ投稿
   - 進捗はSlack通知とNotionデータベースで確認、スマホからはWebアプリで承認・編集

答え忘れた日はストックから投稿され続けるので、投稿が途切れません。月曜朝には「予約の持ち日数」がSlackに届き、弾切れが近いと警告します。

## 全体像

```
 朝8時                        随時                         夜21時               毎時
┌────────────┐   Slackスレッド返信   ┌──────────────┐   ┌──────────────┐   ┌──────────┐
│ テーマ自動選定 │ ─────────────────▶ │ 本人の文体で   │ ─▶│ 品質ゲート     │ ─▶│ X API投稿 │
│ + ニュース取得 │   （インタビュー）    │ 下書き生成     │   │ 採点→予約割当  │   │          │
└────────────┘                      └──────────────┘   └──────────────┘   └──────────┘
        │                                  │                  │                │
        └──────────────── スプレッドシート（DB） / Notion同期 / Slack通知 ────────────┘
                                    スマホ確認: GAS Webアプリ
```

- **文体の再現**: `Voice` シートに自分の過去ポストを貼っておくと、生成・採点の両方でお手本（few-shot）として使われます。AIっぽい定型文は採点で減点されます。
- **ストック型**: 閾値未満の下書きも捨てずに `stock` として保持。予約は「いつ何を出すか」を考えず、スコア順に空き枠へ自動で埋まります。
- **安全装置**: `DRY_RUN=true`（既定）の間はXへ投稿せずSlackに内容を流すだけ。`AUTO_APPROVE=false`（既定）の間は品質ゲート合格後にワンタップ承認が挟まります。運用が安定したら両方外せます。

セットアップ手順・必要なAPIキー・トリガー設定は **[gas/README.md](gas/README.md)** を参照してください。

## モバイル確認

- **Slack**（スマホアプリ）: インタビュー回答・生成結果・投稿通知はすべてSlackで完結
- **GAS Webアプリ**（スマホ対応UI）: ストック一覧・承認・却下・本文編集・手動予約。ホーム画面に追加すればアプリのように使えます
- **Notion**: ストックのデータベースビュー（ステータス・スコア・予約日時）
